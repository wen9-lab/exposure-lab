# Windows 1/3 EV 曝光目标修正计划

## 已核对的前提

当前完整档计算器的曝光目标滑块 step=1；精细档的 step=1/3，但显示为两位小数。档位速查的完整档补偿刻度只有整档。计算内核 targetEV 已是数值输入，可计算 1/3 EV；补偿目标本身不改变实际曝光。

## 目标和边界

- 两个计算器的曝光目标统一支持 −5 到 +5 EV 的 1/3 档，界面显示 0、±0.3、±0.7、±1 等近似相机读数，内部计算保留精确 1/3 与 2/3。
- 增加明确的 ±1/3 EV 控件并保留滑块；完整档光圈、快门、ISO 仍按整档调整，目标无法达到时显示剩余 EV。
- 档位速查页的曝光补偿刻度统一展示 1/3 EV。
- 旧版本地数据与 JSON 备份继续可读，两个计算器继续各自保存曝光目标。
- 仅构建与本机检查 Windows 安装包；不发布网页，不构建或验收 Android 与 Mac/iPhone，直到用户确认 Windows 版没有问题。

## 实施步骤

1. 先写浏览器失败测试：完整档依次点出 +0.3/+0.7/+1，校验重启保留、真实残差与不误报等效；精细档 +1/3 和 ISO 125 验证档位等效；速查页显示完整 1/3 刻度。
2. 写核心边界测试：目标 +1/3 的真实 residual，完整档只能到整档时保留 ±2/3 残差；精细档 ISO 125 时 nominalEV=1/3、actualEV≈0.321928、residual=0。
3. 实现整数刻度 −15…15 与目标 EV=刻度/3 的转换，显示一位小数，加入步进按钮和刻度说明；修正状态/警告清理，避免改目标后沿用旧限制提示。
4. 运行单元、浏览器、窄屏和 Windows 构建；安装 0.1.2 到 E 盘并启动，检查版本与窗口。记录 Windows 待用户现场确认项；其他平台继续待处理。
