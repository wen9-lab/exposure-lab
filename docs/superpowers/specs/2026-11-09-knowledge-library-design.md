# 曝光知识库深化设计（2026-11-09）

## 目的与读者

让以摄影初学者为主、兼顾进阶的用户，不只知道怎么调参数，还明白参数变化的原因、数学关系、画面取舍和在现场如何判断。现有知识库只有 8 张折叠卡片，每张约一段概述及一条短例，无法满足原需求书的图文、表格和可展开的详细解释。

## 范围与边界

- 沿用现有 React/Tauri/PWA 架构，所有正文、表格和示意图随应用打包，离线可读。
- 只深化知识库；两个计算器、速查表、持久化格式和计算口径不改。
- 完整指覆盖原需求书列出的曝光知识主题及常见判断链，不扩展为整套摄影百科。
- 案例数字标为教学假设或经验起点，避免暗示对任意现场都有正确曝光。
- 区分物理进光量、按 ISO 估算的输出亮度趋势、传统 EV 值和本软件的相对 ΔEV。

## 考虑的方式

1. 原 8 张卡片内直接扩写：改动小，但长文塞在双列卡片里，阅读路径和查找困难。
2. 采用分章节的循序课程：页首提供目录，正文按概念、计算、应用排列；每章有核心结论、详细解释、算例、误区与边界，必要时配本地表格或 CSS 示意。更适合初学者逐步读，也利于以后修订。

## 内容结构

1. 先建立曝光模型：场景亮度与主体反射率、光圈/快门决定像面曝光、ISO 对数码输出的影响；解释同一参数组合在不同现场不能保证照片一样亮。
2. 光圈、快门、ISO 分别做什么：f 值与通光面积、景深趋势及其条件；快门时长与运动模糊；数码 ISO 与噪声/高光余量，胶片 ISO 固定。用只改一个参数的表格对照。
3. 一档与 1/3 档的数学：倍增/减半、光圈 √2、快门 ×2、ISO ×2；从 f/4 到 f/2.8 和 1/500 到 1/1000 分步算出抵消；解释相机标称值取整及 +0.029 EV。
4. EV、测光与曝光补偿：传统 EV = log₂(N²/t) 与本软件相对亮度 ΔEV 的符号区别；测光为何会受雪、逆光、深色背景影响；补偿是目标，必须由实际参数变化实现。给出 +1 EV 手动参数例子及受锁定/范围限制的残差。
5. 曝光等效与创作取舍：以 f/4、1/500、ISO 100 为基准，列出等效组合、景深和运动表现；解释 ISO 参与输出亮度等效时，物理进光量可能不同。
6. 阳光 16 与天气扩展：晴天理论快门 1/ISO；六种天气/环境起始光圈表与适用限制；ISO 400 的 1/400 理论值、完整档 1/500 约 −0.32 EV；展示选择天气、设 ISO、取快门、试拍检查的流程。
7. 数码与胶片的决策：数码调 ISO 与固定光子数量的区别；胶卷 ISO 400 用 EI 800 测光少一档曝光，EI 不会改变胶卷感光度；显影推拉需另行决定，不能由软件自动假定。
8. 场景实战：晴天人像、运动主体、开放阴影人像、雪地/沙滩、逆光人像、室内弱光。每例都列目标、起始组合、为什么这样改、检查什么、失败时怎么办，至少一例展示超出设备范围后的真实取舍。

## 页面与交互

- 页首保留现有视觉主题，新增课程目录和阅读顺序提示。
- 章节采用单列长文，内部可用小标题、表格、算式和纯 CSS 示意；进阶解释用原生 details 展开，默认正文足以独立理解。
- 目录锚点可跳到章节；手机上正文、表格与图示可读，不产生横向页面溢出；保留触控可操作性。
- 每章末尾有简短的计算器验证指引，不改变计算器状态或自动跳转。
- 外部资料只用于编辑校核，内容本身不依赖链接或网络。

## 校核与验收

- 以原需求书、现有计算模型及相机制造商的基础教学资料交叉核对数字和措辞。
- 自动化检查 8 章目录、每章的解释/算例/边界、关键教学数字与锚点交互；现有单元与浏览器测试继续通过。
- 桌面和 390 px 手机视口检查阅读布局，构建 Pages 版本并验证离线缓存可读。
- 发布后更新 GitHub Pages；Windows/Android 安装包涉及内容变更，需重建并替换交付产物，旧包不可标作含新版知识库。真实设备离线验收仍按交付记录独立标记。
