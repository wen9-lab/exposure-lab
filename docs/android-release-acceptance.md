# Android 正式版安装与验收指南

适用版本：0.1.2 正式签名版（versionCode 1002，包名 `io.github.wen9lab.exposurelab`）

## 0. 重要：与旧调试版的关系

正式版包名 `io.github.wen9lab.exposurelab` 与旧调试版 `io.github.wen9lab.exposurelab.debug` **是两个不同的应用**，且签名不同，因此**不能覆盖安装**。这不是缺陷，而是 Android 的安全机制（包名 + 签名共同决定应用身份）。

迁移步骤：

1. 打开旧调试版，进入设置，导出 JSON 备份并保存到手机文件或发送到电脑。
2. 卸载旧调试版（设置 → 应用 → 摄影曝光实验室 → 卸载）。
3. 安装本正式版。
4. 进入设置，导入刚才的 JSON 备份，核对预设与历史记录是否恢复。

若不卸载旧版直接安装，会得到两个独立应用，数据不互通；这种情况也属正常，可按需删除其中一个。

## 1. 安装

1. 把 APK 传到安卓手机（数据线、微信文件传输助手、网盘均可）。
2. 在手机上点击 APK 安装。系统会提示"未知来源应用"，选择允许/信任。
   - 这是自签名个人分发的正常提示。正式版非应用商店分发，无法避免。
3. 若提示"应用未安装"或"签名冲突"，见第 5 节排障。

安装成功后，桌面出现"摄影曝光实验室"图标，包名为 `io.github.wen9lab.exposurelab`（无 `.debug` 后缀）。

## 2. 断网重开验收（核心）

本应用的核心承诺是**完全离线可用**。请严格按此顺序验证：

1. 首次启动后，让应用完成初始化。
2. **断开 Wi-Fi 和移动网络**（开启飞行模式最稳妥）。
3. 彻底退出应用：从最近任务列表划掉，确认进程结束。
4. 重新打开应用。
5. 依次打开全部五个页面，确认无空白、无报错、无联网提示。
6. 在完整档与 1/3 档两个计算器上调整光圈、快门、ISO，确认计算正常。

若能全部通过，说明离线内核与资源打包正确。

## 3. 计算结果验收（A–F 六例）

在完整 1 档计算器上，以 f/4、1/500 秒、ISO 100 为基准，验证：

- **A 档位等效偏差**：改为 f/2.8、1/1000 秒、ISO 100，标称 EV 应为 0，但界面显示的实际偏差约为 `+0.029 EV`。
- **B ISO 只改推算亮度**：改为 f/4、1/1000 秒、ISO 200，进光量变化应为 `-1 EV`，但推算亮度等效（标称 EV = 0）。
- **D 阳光 16**：ISO 400 晴天，理论精确模式快门为 1/400 秒，标准档位模式为 1/500 秒。

在 1/3 档计算器上验证：

- **C 三分之一档等效**：f/2.8、1/250 秒、ISO 100 → f/3.2、1/200 秒、ISO 100，标称 EV 为 0，实际偏差约 `-0.063 EV`。

其他：

- **E 胶片模式**：切换到胶片相机后，调整快门，ISO 不应自动改变。
- **F 越界提示**：当参数超出设备范围时，不应误报"完全等效"，应显示残余偏差。

## 4. 数据留存验收

1. 保存若干预设。
2. 断网彻底退出并重新打开，确认预设仍在。
3. 导出 JSON 备份到手机文件。
4. 清除应用数据或删除部分预设后，导入刚才的 JSON，确认恢复。

## 5. 常见排障

**Q：安装时提示"应用未安装"**
- 确认 APK 架构为 arm64-v8a。本包仅支持 ARM64 设备；若手机是较旧的 32 位 ARM 或 x86 架构，无法安装。
- 确认手机系统版本 ≥ Android 7.0（minSdk 24）。

**Q：提示"签名冲突"或"应用已存在，签名不同"**
- 说明手机上装了同包名但不同签名的版本。请先卸载后再安装。
- 若装的是旧 `.debug` 版，包名不同，不会发生此冲突，而是两个应用并存。

**Q：安装后无法打开或闪退**
- 确认 Android WebView 版本较新。本应用依赖系统 WebView 渲染界面。
- 在设置中清除本应用数据后重试。

**Q：断网重开后页面空白**
- 确认首次启动时是联网完成的初始化；首次缓存需要网络。
- 之后即可离线。若清除过应用数据，需重新联网初始化一次。

**Q：升级新版本后数据丢失**
- 升级前务必导出 JSON 备份。跨签名或跨包名的升级不会自动迁移数据。
- 同包名同签名的小版本升级（本正式版之后的更新）会保留数据。
